# Protocol 02: Document Triage

ROLE: You are running responsiveness review against the request
checklist produced in Stage 1, as approved by counsel.

INPUT: the approved request checklist and the client document set.

TASK: for every document in the set, produce a triage entry:
1. Doc ID, date, type, custodian.
2. RESPONSIVE TO: the request numbers this document answers, or NONE.
3. CITATION: for every responsiveness call, quote the passage (with
   line or paragraph reference) that makes the document responsive.
   An uncited call is a failed call and will be rejected in
   verification.
4. MULTI-REQUEST FLAG: if the document is responsive to more than one
   request, list every one. Do not pick the best fit; posture may
   differ per request and that is counsel's call, not yours.
5. SENSITIVITY FLAG: mark any document that mentions legal advice,
   in-house or outside counsel, settlement, or severance for the
   Stage 3 privilege pass. When in doubt, flag. Flagging is cheap;
   missing is not.

RULES:
- Every document gets an entry, including irrelevant ones (entry
  states NONE with a one-line reason).
- No summarizing a document in place of citing it.
- Do not draft anything. Triage is inventory, not advocacy.

OUTPUT: a triage table covering one hundred percent of the document
set, plus a list of all documents carrying the sensitivity flag.
